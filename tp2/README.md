# Your Album Critic - TP2

## Como executar

1. Instale as dependências:
```
npm install
```

2. Inicie o servidor:
```
npm start
```

3. Acesse: http://localhost:3000

## Usuários padrão
- **Admin:** login `admin` / senha `123`
- **Usuário comum:** login `user` / senha `123`

## Funcionalidades
- Home com carrossel, cards, pesquisa e gráfico
- Login e cadastro de usuários
- Favoritos por usuário logado
- CRUD de álbuns (somente admin)
- Página de detalhes com faixas e análise IA
